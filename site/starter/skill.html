Live Paper skill

Make a vibe-coded app belong on the DC-1.

The daylight-ify pack teaches your agent the medium: 10.5″ Live Paper, 1600×1200, 4:3 greyscale, Wacom EMR, Sol:OS. Port, then design, then teach — preview after every visual pass.

Install the pack

In Claude Code:

/plugin marketplace add a12k-a2b/daylight-computing-club-community-hub
/plugin install daylight-ify@daylight-computer-club

Or copy the folders into a project:

cp -r skills/daylight-* your-app/.claude/skills/

Skills live in the club repo: skills/ — daylight-port, daylight-design, daylight-preview, daylight-teach.

The daylight-ify prompt

Paste this when the app already runs on a color monitor and you want it on the tablet:

Daylight-ify this app for the Daylight DC-1.

Read the club skill pack and apply it, in order:
1. skills/daylight-port/SKILL.md — pick PWA / WebView shell / native, fix web↔Android collisions.
2. skills/daylight-design/SKILL.md — grayscale that reads on Live Paper, 10.5″ 4:3 layout, touch/stylus/voice, keep the app’s soul.
3. skills/daylight-preview/SKILL.md — render at DC-1 geometry, fix contrast, 48px targets, overflow.
4. skills/daylight-teach/SKILL.md — a short teaching layer so a friend understands it.

Official paths only. Do not add unofficial flashers, root exploits, or Magisk.

Calibrate on the tablet
