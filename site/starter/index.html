First hour

The official path for a new DC-1 — then the club.

A new Daylight should have a first hour that feels like a friend walking you through it. Six short flows. Official OEM unlock and official restore images only. No exploits, no unofficial flashers, no “just run this payload.”

If the tablet is already a friend — skip unlock and recover. Start at tools, or just go to the shelf.

  1. 1 · UNLOCK

    Official OEM unlock

    Turn on OEM unlocking, send your serial to Daylight, wait for the official token. This is how elevated apps become possible.

    Unlock wipes the tablet. Back up first.
  2. 2 · RECOVER

    Official-image recover

    Safe official first aid, Daylight’s own factory reset, then a request for an official restore image if it still won’t boot.

    Nothing unofficial gets written to the tablet.
  3. 3 · TOOLS

    Keys, Shizuku, glass, clubhouse

    The key mapper, Club Shizuku for elevated apps, Tracing Paper, and the Clubhouse — the dishes that make the tablet yours.
  4. 4 · CONNECT

    ADB and wireless debugging

    Official platform-tools on a Mac, USB debugging, then wireless so Claude or Codex can sit on the desk.
  5. 5 · SKILL

    Live Paper skill

    The daylight-ify pack: port, design, preview, teach — so a vibe-coded app belongs on Live Paper.
  6. 6 · BUILD

    Cherry remote build

    Queue a build on a real machine when yours isn’t set up. Mail for now; a cherry server when it exists.

Something already wrong with the tablet? Daylight Rescue is the blank-screen door — still write-locked, official only.
